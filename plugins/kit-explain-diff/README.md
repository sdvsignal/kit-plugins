# kit-explain-diff

`/kit-explain-diff:run` reads `git diff` (and staged changes) and gives you 3–6 plain-English bullets a non-author can follow, plus the risky lines as `file:line` with why they're risky and what to test. Read-only: it never edits.

```
/plugin marketplace add sdvsignal/kit-plugins
/plugin install kit-explain-diff@kit-plugins
```
